What is a Tesla Referral Link?

A Tesla Referral Link is a personal Tesla link shared by an existing customer. Tesla's referral program can provide benefits to eligible new and existing customers when a qualifying Tesla product is purchased through a valid referral link.

For buyers in Germany, the important practical point is to open the referral link before placing the Tesla order. Tesla states that referral links cannot be applied to an order after it has already been placed.

Always verify the final offer: Tesla can change referral benefits, eligible products and campaign conditions. The Tesla checkout/referral page shown immediately before ordering is the source you should rely on.

How to use my Tesla Referral Link

  1. Open the referral link first. Use my Tesla referral link before starting or completing your vehicle order.
  2. Check the referral benefit. Confirm that Tesla shows the expected buyer benefit for the model you want.
  3. Select and configure your Tesla. Choose the vehicle, version, paint, interior and other options.
  4. Complete the order through the referral flow. Do not assume the link can be added later to an existing order.
