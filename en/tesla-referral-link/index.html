Frequently asked questions

Can I add the link after ordering?

Tesla states that referral links cannot be applied after an order has been placed.

What if no benefit appears?

Do not assume it will appear automatically later. Check the market, vehicle and eligibility; resolve uncertainties with Tesla before ordering.

Is a referral code the same as a referral link?

People often use these terms for the same order route. Use the complete link rather than relying on entering a code later.
